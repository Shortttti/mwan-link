# Mwan Link Portal

⚠️ شرط أساسي جدًا للتصميم يجب أن يكون تصميم Mwan Link مطابقًا بشكل واضح ومتناسق مع التصميم الحالي لمنصة موان الرسمية. لا أريد إنشاء هوية بصرية جديدة لـ Mwan Link، ولا أريد تصميمًا مختلفًا أو شاذًا عن منصة موان. يجب الحفاظ على: • نفس الهوية البصرية لمنصة موان. • نفس الألوان المستخدمة في منصة موان. • نفس أسلوب الخطوط Typography. • نفس شكل الأزرار. • نفس أسلوب البطاقات Cards. • نفس أسلوب القوائم والتنقل Navigation. • نفس المسافات والأحجام والتنسيقات قدر الإمكان. • نفس أسلوب الأيقونات والعناصر البصرية. • نفس الـHeader والـFooter وأسلوب الصفحات. • نفس أسلوب عرض الخدمات داخل منصة موان. Mwan Link يجب أن تبدو وكأنها خدمة رسمية موجودة أصلًا داخل منصة موان، وليست موقعًا أو تطبيقًا جديدًا تم تصميمه بشكل منفصل. عند الانتقال من منصة موان إلى Mwan Link، يجب ألا يشعر المستخدم أنه انتقل إلى منصة أخرى. لا تضف: • ألوانًا غريبة. • Gradients غير موجودة في تصميم موان. • Animations مبالغًا فيها. • عناصر زخرفية غير موجودة في موان. • أسلوب Marketplace تجاري. • تصميم Startup مختلف عن موان. • أي عنصر بصري لا يتناسب مع الهوية الرسمية للمنصة. الأولوية القصوى هي الحفاظ على هوية وتصميم منصة موان الحالية، وإضافة وظائف Mwan Link داخلها بشكل طبيعي ومتناسق، مع عدم تغيير التصميم الأساسي لمنصة موان. إذا كان هناك تعارض بين تصميم مقترح لـ Mwan Link وبين تصميم موان، يجب دائمًا تفضيل تصميم موان والالتزام به.
